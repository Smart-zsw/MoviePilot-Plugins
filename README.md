# MoviePilot-Plugins

> [!NOTE]
> [MoviePilot](https://github.com/jxxghp/MoviePilot) V3 第三方插件仓库

## 插件列表

#### 网盘类插件

- [本地115镜像](./plugins.v3/localmirror115/README.md)：本地媒体库实时同步到 115 网盘，并把非视频文件复制到 STRM 目录；本地实体库只读，删除进入 115 回收站。

## 使用方法

在 MoviePilot 的“插件市场仓库地址”中加入下面的地址（多个仓库用英文逗号分隔），保存后刷新插件市场即可搜索安装：

```text
https://github.com/Smart-zsw/MoviePilot-Plugins/
```

需要 MoviePilot V3（3.2.5 及以上）。各插件的配置与注意事项见各自的说明文档，也可以在插件市场详情的“使用说明”中查看。

每个版本都以 [GitHub Release](https://github.com/Smart-zsw/MoviePilot-Plugins/releases) 压缩包发布，MoviePilot 默认优先从 Release 安装；需要时也可以在插件市场中选择历史版本安装。
